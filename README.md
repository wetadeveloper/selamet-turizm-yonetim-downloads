# Selamet Turizm Yönetim — Windows

[Windows kurulum dosyasını indir](https://github.com/wetadeveloper/selamet-turizm-yonetim-downloads/releases/latest/download/SelametTurizm-Yonetim-Setup.exe)

Bu bağlantı her zaman en son sürümü indirir.

1. **SelametTurizm-Yonetim-Setup.exe** dosyasını açın.
2. "Windows bilgisayarınızı korudu" uyarısı çıkarsa **Ek bilgi → Yine de çalıştır** seçin.
3. Türkçe kurulumu tamamlayın.
4. Başlat menüsünden **Selamet Turizm → Yönetim** uygulamasını açın.
5. Şirketinizin tanımladığı e-posta ve şifrenizle giriş yapın.

Windows 10 (2004 veya üzeri) / Windows 11, x64 ve internet bağlantısı gerekir.
Bu deneme sürümü dijital olarak imzalı değildir; Windows SmartScreen uyarısı gösterebilir.
Windows güvenlik ayarlarını kapatmayın.

Yeni sürümler uygulamanın ana ekranında gösterilir. **Güncelle** düğmesi dosyayı indirip
doğrular, kurar ve uygulamayı yeni sürümle yeniden açar.

[Sürümler ve dosya doğrulaması](https://github.com/wetadeveloper/selamet-turizm-yonetim-downloads/releases)

Bu depo yalnız kurulum dosyalarını ve açıklamaları içerir. Uygulamanın kaynak kodları
ayrı, gizli depoda tutulur. İndirme bağlantısı şirket verilerine erişim yetkisi vermez.
